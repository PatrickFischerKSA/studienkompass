# Studienkompass

Deutschsprachiges Orientierungstool für Wege nach der FMS, Fachmaturität oder gymnasialen Matura in der Schweiz. Es basiert auf „Ready for… Laufbahngestaltung nach der Matura“ der Berufs-, Studien- und Laufbahnberatung des Kantons Schwyz.

Öffne `index.html` im Browser. Für GitHub Pages wähle unter **Settings → Pages** die Veröffentlichung vom Branch `main` aus dem Ordner `/ (root)`. Es ist kein Build nötig.

Das Profil sortiert Wege nach der Anzahl passender Interessen. Ein Vergleich von bis zu drei Wegen und eine Checkliste unterstützen die weitere Recherche. Eingaben werden im Browser gespeichert.
